# Quiz Master — интерактивті тестілеу жүйесі

## Сипаттамасы
Quiz Master — бұл пайдаланушыға жауап нұсқалары бар сұрақтар қоятын, жауаптарды текетін және нәтиже есептейтін Python тіліндегі консольдік бағдарлама.

## Жобаның мақсаты
Жауаптарды автоматты түрде тексеріп, нәтижесін ұпаймен және пайызбен көрсететін қарапайым тестілеу жүйесін жасау.

## Мүмкіндіктері
- Сұрақтар мен A, B, C, D нұсқаларын көрсетеді.
- Пайдаланушы енгізген деректі тексереді.
- Жауаптың дұрыс немесе бұрыстығы туралы хабарлайды.
- Қате болған жағдайда дұрыс жауапты көрсетеді.
- Ұпайлар мен пайыздық нәтижені есептейді.
- Нәтижеге пайыздық мөлшері бойынша баға шығарады.

## Талаптар
- Python 3
- Қосымша кітапханалар қажет емес.

## Іске қосу
1. Репозиторийді жүктеп алыңыз немесе клондаңыз.
2. Жоба папкасын терминалда ашыңыз.
3. Мына пәрменді іске қосыңыз:
   ```bash
   python quiz_master.py
   ```
   Егер `python` пәрмені жұмыс істемесе, `python3 quiz_master.py` деп көріңіз.

## Қалай пайдалану керек
1. Бағдарламаны іске қосыңыз.
2. Сұрақ пен жауап нұсқаларын оқыңыз.
3. `A`, `B`, `C` немесе `D` әрпін енгізіңіз.
4. Соңғы сұрақтан кейін бағдарлама қорытынды нәтижені көрсетеді.

## Қолданылған Python конструкциялары
- Сұрақтарды сақтауға арналған тізім (`list`).
- Сұрақ мәтінін, нұсқаларын және дұрыс жауабын сақтауға арналған сөздік (`dict`).
- Сұрақтар мен нұсқаларды қарап шығуға арналған `for` циклі.
- Рұқсат етілген енгізуді тексеруге арналған `while` циклі.
- Жауапты тексеру және нәтиже шығару үшін шартты операторлар `if/elif/else`.
- Енгізу мен шығаруға арналған `input()` және `print()` функциялары.
- Сұрақ санын есептеу үшін `len()`.

## Тестілеу
Бағдарламаны мына сценарийлер арқылы тексеріңіз:
1. Дұрыс жауап — ұпай 1-ге көбеюі тиіс.
2. Қате жауап — бағдарлама дұрыс нұсқаны көрсетуі керек.
3. A/B/C/D әріптерінен басқа символ енгізу — бағдарлама енгізуді қайта сұрауы тиіс.
4. Барлық жауап дұрыс — қорытынды 100% болуы керек.
5. Бестен үш дұрыс жауап — қорытынды 60% болуы керек.
